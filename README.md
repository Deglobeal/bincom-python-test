# Bincom Python Assessment

Python solutions for the Bincom ICT Solutions preliminary Python
developer assessment.

## Requirements

- Python 3.12 or compatible
- Git

## Setup

Clone the repository and enter the project directory:

    git clone https://github.com/Deglobeal/bincom-python-test.git
    cd bincom-python-test

Create and activate a virtual environment:

    python3 -m venv .venv
    source .venv/bin/activate

Run the current solution:

    python main.py

## Project Status

The initial solution analyzes dress-color entries recorded across
five weekdays. The project will be organized into individual question
modules as the assessment progresses.

## Data Notes

- The original entries `ARSH` and `BLEW` are preserved as recorded.
- Potential spelling errors will be reviewed rather than silently corrected.
- The mean, median, and variance calculations currently operate on the
  frequencies of the recorded color labels, not on the color names themselves.
